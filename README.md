# Al-Quran Bangla AI (আল-কুরআন বাংলা) 🕌

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-1.2.0-emerald.svg)](https://github.com/shahin-prpl/al-quran-bangla-ai)

A premium, AI-integrated Quranic platform tailored for the Bangla-speaking community. This application combines the timeless wisdom of the Holy Quran with cutting-edge AI technology to provide deep spiritual insights and accessibility.

## 🌟 Key Features

- **📖 Complete Quran Experience**: Full 114 Surahs with high-fidelity Arabic script and accurate Bangla/English translations.
- **🎙️ Live AI Voice Assistant**: Ask spiritual or historical questions about the Quran and get real-time audio responses.
- **🧠 Intelligent Tafsir**: Generate contextual explanations (Tafsir) for any verse using Google Gemini AI.
- **🔍 Semantic Search**: Search the Quran by topic (e.g., "Patience", "Inheritance") instead of just keywords.
- **🎧 Master Reciters**: Stream soulful recitations from 12 world-renowned Qaris including Alafasy and Minshawi.
- **🕋 Daily Utility**: Real-time prayer timings based on your exact location and a Ramadan countdown.
- **🎨 Modern Aesthetics**: Fluid animations, Dark Mode, and customizable typography for an optimal reading experience.

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Safari, Edge).
- A Google Gemini API Key (stored in your environment as `API_KEY`).

### Installation
1. Clone the repo:
   ```bash
   git clone https://github.com/shahin-prpl/al-quran-bangla-ai.git
   ```
2. Serve the directory:
   ```bash
   npx serve .
   ```

## 📱 Mobile Installation (PWA)
This app is fully PWA-compliant.
- **Android**: Open in Chrome and select "Add to Home Screen".
- **iOS**: Open in Safari, tap the Share icon, and select "Add to Home Screen".
